# Vehicles_app
Proyecto TripleTen
En este proyecto se realizó una aplicación web donde al presionar un botón este crea un histograma o grafico de dispersión del archivo csv que se tiene, en este caso creara un grafico de dispersion de la venta de carros en estados unidos, esto nos ayuda a visualizar los datos de una manera más clara e interactiva, con lo cual nos permite analizar los datos para tomar decisiones.
El proyecto se ejecuta en Jupyter notebooks, se uso principalmente el lenguaje de programacion python, asi como de sus librerias pandas, plotly_express y streamlit.
